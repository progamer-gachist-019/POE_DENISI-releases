# POE DENISI — демо для Windows

Публичные сборки личной ARPG к дню рождения Дениса.

## Скачать и запустить

**[Скачать демо 0.0.1 для Windows x64](https://github.com/progamer-gachist-019/POE_DENISI-releases/releases/download/v0.0.1/POE_DENISI-0.0.1-windows-x64.zip)** · [Описание версии](https://github.com/progamer-gachist-019/POE_DENISI-releases/releases/tag/v0.0.1) · [Все версии](https://github.com/progamer-gachist-019/POE_DENISI-releases/releases)

1. Скачайте ZIP по ссылке выше — вход в GitHub не нужен.
2. Распакуйте весь архив в одну папку.
3. Запустите **POE_DENISI.exe**. Godot устанавливать не нужно.

Windows 10/11 x64, видеокарта с поддержкой Direct3D 12 / Forward+.

## Управление

| Клавиша | Действие |
| --- | --- |
| ЛКМ | Идти |
| ПКМ | Лопата |
| Shift + ПКМ | Удар на месте |
| Q | Тяжка |
| W | Мяч после получения способности |
| R | Новая попытка |

В демо: шесть дотеров, Саня-футболист, полоса EXP и слот «Депнуть» после зачистки. Арена и модели временные. Остальные локации и сохранения между запусками ещё не реализованы.

В этом репозитории находятся только описания и готовые сборки. Исходники хранятся в отдельном приватном репозитории. Бесплатные модели Kenney Mini Dungeon используются по CC0; лицензия включена в архив.
